#+TITLE: Signal to Noise
The original QC matlab code runs very slow in an octave container.
This sub-directory tracks an implementation using compiled software instead, namely ANTs and AFNI.

Faster execution will allow near realtime alerting of issues.
Shim error alerts are already by https://github.com:NPACore/file-curator (~examples/shim_notify.py~).

* Faster methods

dostats.m finds the center for each input and runs circshift on each slice. Here we instead get the rigid affine transform that will match input to a template. And warp the unshifted template ROI mask to the new input. Also see https://wiki.mrrc.pitt.edu/doku.php?id=data:qc

#+begin_src bash :results graphics file :file mask_centered.png :exports results

An excerpt from [[file:../Program/dostat.m]] shows reported snr is 120-bin histogram from mean/std of each slice×timepont (src_calc{46*200} {{{results(=9200=)}}}))
#+begin_src matlab :eval never :results none
phansignal = zeros(2, nz,nfile); % 1 - mean; 2 - std
i=1:nfile % volume (time point)
 ll = ii + (jj-1)*mx; % z; mosaic ii=1:my; jj=1:mx
 dataslice = DATA(:,:,ll,i);
 phansignal(1,ll,i) = mean(dataslice1(Iphan1));
 phansignal(2,ll,i) = std(dataslice1(Iphan1));
snr = phansignal(1,:)./noisesignal(2,:);
[snrn,snrx] = hist(snr,120);
[M,I] = max(snrn); stat.snrpk = snrx(I)
#+end_src

#+begin_src octave :session
load('../output/sigstat.mat')
nz = size(DATA,3);
nfile = size(DATA,4);
phansignal = zeros(2, nz,nfile); % [mean; std,:,:]
for ll=1:nz
  Iphan1 = find(ALL_MASK(:,:,ll,1)==1);
  for i=1:nfile
   dataslice1 = DATA(:,:,ll,i);
   phansignal(1,ll,i) = mean(dataslice1(Iphan1));
   phansignal(2,ll,i) = std(dataslice1(Iphan1));
  end
end
snr = phansignal(1,:)./noisesignal(2,:);
[snrn,snrx] = hist(snr,120);
[M,I] = max(snrn);
stat.snrpk = snrx(I)

jout = jsondecode(fileread('../output/stats.json'));
#+end_src
